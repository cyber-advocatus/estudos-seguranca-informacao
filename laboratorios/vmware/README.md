# Laboratório VMware

Ambiente de virtualização utilizado para estudos práticos de Sistemas Operacionais, Redes e Segurança da Informação.

## Objetivos

- Estudar virtualização de sistemas operacionais.
- Criar e administrar máquinas virtuais.
- Configurar redes virtuais.
- Praticar administração de sistemas Linux e Windows.
- Simular ambientes de redes para estudos de Segurança da Informação.
- Documentar configurações, testes e evidências.

## Máquinas Virtuais

### Windows 11

Sistema operacional Windows utilizado para estudos de administração, redes, segurança e interoperabilidade com ambientes Linux.

**Status:** Instalado

### Debian

Distribuição Linux utilizada para estudos de administração de sistemas, redes e Segurança da Informação.

**Status:** Em instalação / preparação
